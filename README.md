# Movie Actor Database

A C++ database search system that allows users to search for movies and actors using file-based input and hash map data structures.

## Features
- Search actors by movie
- Search movies by actor
- File input processing
- Query system
- Performance timing metrics
- Data organization using hash maps and sets

## Technologies Used
- C++
- STL Containers
- unordered_map
- unordered_set
- File I/O
- Regular Expressions

Hash maps and sets
File processing

String parsing
